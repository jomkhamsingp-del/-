# ระบบค้นหาราคาฟิกเกอร์

ค้นหาโมเดลฟิกเกอร์จากหมวด Action Figures ใน CollectAIO API (`https://www.collectaio.com/api/v2/search`) พร้อมเรียงราคาด้วย Selection Sort, Insertion Sort หรือ Bubble Sort และค้นหาแบบ Linear Search ในรายการของหน้าปัจจุบัน

## เริ่มต้น

ต้องใช้ Node.js 18 ขึ้นไป

```bash
npm install
npm start
```

เปิด `http://localhost:3000` ระบบใช้ `/figures` เป็น proxy ไปยัง CollectAIO เพื่อหลีกเลี่ยงการเรียก API ข้ามโดเมนจากเบราว์เซอร์

## การค้นหาและเรียงข้อมูล

- ช่องค้นหาหลักส่งคำค้นไปยัง CollectAIO API โดยจำกัดหมวดเป็น `action-figures` เพื่อไม่รวมการ์ดและของสะสมประเภทอื่น
- ค้นหาฟิกเกอร์หรือตัวละครจากชื่อได้ในช่องค้นหาหลัก และกรองประเภทจากหมวดของ CollectAIO
- ราคาจาก API ซึ่งเป็น USD จะแปลงเป็นบาทด้วยอัตราล่าสุดจาก ER API และ cache ไว้หนึ่งชั่วโมง; ราคาต้นฉบับ USD จะแสดงในรายละเอียด
- กรองช่วงราคาเป็นบาทด้วยราคาต่ำสุดและราคาสูงสุด โดยกรองก่อนเรียงและแบ่งหน้า
- API ส่งข้อมูลเป็นหน้า หน้าแรกมี 24 รายการ; ใช้ปุ่มเปลี่ยนหน้าเพื่อเรียกผลลัพธ์ถัดไป
- เลือกจำนวนรายการต่อหน้าได้ 6, 12, 24 หรือ 48 รายการ
- ช่อง "ค้นหาในรายการหน้านี้" ใช้ Linear Search ตรวจชื่อและหมวดหมู่ใน Array ที่โหลดอยู่
- เลือกอัลกอริทึมและทิศทางเพื่อเรียงราคาของหน้าปัจจุบัน รายการที่ไม่มีราคาจะอยู่ท้ายสุด
- ราคาที่แสดงและบันทึกใหม่ใช้หน่วยบาท; รายการเก่าที่ไม่มีหน่วยจะถือเป็น USD และแปลงให้ตอนแสดงผล
- ผลลัพธ์แสดงรูปภาพ ราคา ร้านค้า/แหล่งราคา สภาพสินค้า ความเชื่อมั่น และจำนวนตัวอย่างราคาเมื่อมีข้อมูล

ตัวอย่างเรียก backend: `/figures?q=figure&type=The%20Black%20Series&min_price=700&max_price=1400&page=1&sort=selection&direction=asc`
